Experience Bands (Node.js)
0–2 years (Foundations)
- Core: modules, npm scripts, package.json, env vars, basic debugging
- HTTP: express basics, routing, middleware, error handling, REST basics
- Async: callbacks/Promises/async-await, setTimeout/Immediate, process.nextTick
- Data: CRUD with one DB, connection basics, basic indexes
- Streams/buffers: read/write basics, piping
- Security basics: Helmet, input validation, rate limits, CORS

3–6 years (Intermediate)
- Architecture: layered structure, config management, feature flags
- Observability: logs, metrics, tracing basics; health checks
- Performance: clustering basics, connection pools, caching (Redis)
- Testing: integration tests, mocking IO, concurrency tests, CI basics
- Reliability: retries/timeouts/circuit breakers, graceful shutdown basics
- Packaging: ESM/CJS interop, exports field, Docker basics

7–10 years (Advanced)
- libuv/event loop internals; tuning server timeouts and keep-alive
- Streams and backpressure at scale; memory/GC tuning; leak diagnosis
- Concurrency: Worker Threads vs Cluster vs processes, scheduling trade-offs
- Security & supply chain: policy.json, provenance, least-privilege, secret rotation
- Large scale ops: OpenTelemetry, SLOs, budgets, traffic shaping, load shedding
- Data & messaging: Kafka patterns, idempotency/outbox, distributed locks
